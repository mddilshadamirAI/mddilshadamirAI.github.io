The Founder's Journey

The Spark: My journey didn't start in a high-tech lab; it started with a single question: "Can I build the future on a Chromebook?" With 8GB of RAM and an Intel processor, I realized that hardware isn't the limit—execution is.

The Sprint: In early April 2026, I committed to a 180-day sprint. Within the first weeks, I moved beyond basic Python to build apps with real interfaces, learning to self-host infrastructure using Docker basics.

Building the Lab: I didn't just study; I deployed. From a calculator app on GitHub Pages to a Clinic Management System on Streamlit, I proved that continuous building delivers professional tools fast.

Looking Ahead: Every commit is a step toward Bengaluru, where I plan to immerse myself in the tech ecosystem. This isn't just code; it's the blueprint of my career.

Overcoming Setbacks: While working on my Chromebook, an unexpected hardware mishap forced a break of over 10 days. Losing a hard-fought GitHub streak hurts, but the resilience built through overcoming these obstacles matters more than any streak counter.
